- La aplicación web de LiteFarm almacena datos como parte de un proyecto de investigación global y no comercial coordinado por la UBC.
- La aplicación solo almacenará datos de contacto, la ubicación de su finca y los datos de gestión que usted ingrese.
- La investigación solo utiliza datos desidentificados. Nunca vendemos sus datos y solo compartimos datos desidentificados para investigaciones académicas y no comerciales sobre la transformación de sistemas alimentarios sostenibles.
- Puede retirar o eliminar sus datos en cualquier momento enviándonos un correo electrónico a [litefarm.team@ubc.ca](mailto:litefarm.team@ubc.ca). Puede ver los resúmenes de sus datos individuales usando sus credenciales de LiteFarm en [data.litefarm.org](https://data.litefarm.org/).

Este resumen es una guía, no el acuerdo. La política completa que figura a continuación es lo que usted acepta al recopilar o almacenar los datos de su finca en la aplicación LiteFarm.
